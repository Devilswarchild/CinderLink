# Security Policy

CinderLink is built to keep players safe: nobody should be able to find your IP address through it, join a world
they weren't invited to, or read or fake your friends' status. If you find a way around any of that, please let
us know privately so it can be fixed before it's misused.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Instead, go to the **Security** tab of this repository and click **Report a vulnerability**. Only the
maintainer can see the report.

Please include:

- What the problem is and what someone could do with it
- Steps to reproduce it, if you can
- The CinderLink, Minecraft and NeoForge versions you tested with

You should get a reply within a few days. Once a fix is released, the issue can be made public, and you'll be
credited unless you'd rather not be.

## What counts as a security problem

- Revealing a player's IP address or location (in the game, in logs, or on the network)
- Joining a world without being one of the friends the host picked
- Reading, faking or tracking a player's online or hosting status without being their friend
- Taking over someone's Cinder Code, identity or friends list
- Anything that lets a stranger crash or harm another player's game through CinderLink

Ordinary bugs, such as a friend not showing up or a button not working, should go in a normal
**Bug report** issue instead.

## Supported versions

Only the latest release of CinderLink receives security fixes. Please update before reporting.
